# Changelog

## [1.0.0] - 2026-11-15

### Added

- JSON timeline model with lanes, events and status colours.
- Deterministic SVG renderer: axis ticks, gridlines, lane labels, tooltips and
  escaped text.
- Automatic or explicit time axis with clipping warnings.
- `render` and `demo` commands with `--out` and `--width`.
- pytest suite for layout, escaping, clipping, determinism and CLI.
